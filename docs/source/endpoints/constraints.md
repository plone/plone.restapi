# Constraints

```{note}
These docs are generated by code tests, therefore you will see some `test` content types appear here.
```

Plone lets an editor restrict which content types can be added to a folder ({menuselection}`Add new --> Restrictions…`).
The `@constraints` endpoint exposes those settings so a frontend can read and update them.

`@types` still reports **effective** addability for the {menuselection}`Add` menu.
Use `@constraints` to configure the policy.

| Verb    | URL             | Action                                      |
| ------- | --------------- | ------------------------------------------- |
| `GET`   | `/@constraints` | Read constraint settings for this context   |
| `PATCH` | `/@constraints` | Update constraint settings for this context |

`GET` requires the `View` permission.
`PATCH` requires `Modify portal content` and the `Modify constrain types` permission.


## Reading constraints

Send a `GET` request to the `@constraints` endpoint on a folder:

```{eval-rst}
..  http:example:: curl httpie python-requests
    :request: ../../../src/plone/restapi/tests/http-examples/constraints_get.req
```

The server responds with the current mode and the effective type lists:

```{literalinclude} ../../../src/plone/restapi/tests/http-examples/constraints_get.resp
:language: http
```

`mode` is one of:

`disabled`
:   Use the portal type defaults ({guilabel}`Use portal default`)

`enabled`
:   Use the lists set on this folder ({guilabel}`Select manually`)

`acquire`
:   Inherit from the parent folder ({guilabel}`Use parent folder settings`)

`locally_allowed_types` is the full set of types that may be added.
`immediately_addable_types` is the subset shown directly in the {menuselection}`Add` menu.
The remaining allowed types typically appear under {menuselection}`More…`.

`configurable` is `false` when the context does not support constraints, for example, a Page.
In that case `mode` is `null` and the type lists are empty.


## Updating constraints

Send a `PATCH` request with any combination of `mode`, `locally_allowed_types`, and `immediately_addable_types`.

`immediately_addable_types` must be a subset of `locally_allowed_types`.
Both lists must be a subset of the types that are addable on this folder by default.

```{eval-rst}
..  http:example:: curl httpie python-requests
    :request: ../../../src/plone/restapi/tests/http-examples/constraints_patch.req
```
